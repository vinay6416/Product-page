# 🛍️ ShopEase - Product Page Website

ShopEase is a modern and responsive product page website created using HTML, CSS, and JavaScript.  
This project includes product cards, product detail popup, image gallery, color and size selection, cart functionality, offers, and responsive design.

---

# 🚀 Features

✅ Modern Responsive UI  
✅ Product Cards  
✅ Product Detail Popup  
✅ Multiple Product Images  
✅ Select Product Color  
✅ Select Product Size  
✅ Add To Cart Functionality  
✅ Cart Counter  
✅ Product Offers  
✅ Smooth Scrolling Navigation  
✅ Responsive Design for Mobile & Desktop  
✅ Attractive Popup Animation  

---

# 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
